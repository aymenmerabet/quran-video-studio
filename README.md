# 🕌 استوديو القرآن الكريم | Quran Video Studio & Sync Player

تطبيق ويب حديث وعالي الأداء لتوليد وتشغيل مقاطع القرآن الكريم بدقة عالية ورسم عثماني مع التزامن الصوتي وتصدير الفيديو لشبكات التواصل الاجتماعي (Reels, TikTok, YouTube, Instagram) مباشرة من المتصفح بدون استهلاك المعالج.

---

## 🌟 الميزات الرئيسية (Features)

- **🎨 تصميم إسلامي فاخر (Luxury Emerald & Gold):** واجهة زجاجية عصرية تدعم الوضع المظلم وتأثيرات الجزيئات والتوهج الذهبي.
- **📖 الرسم العثماني المعتمد:** استخدام خطوط `Amiri Quran` و `Scheherazade New` مع التشكيل الكامل وعلامات الوقف وأرقام الآيات المزخرفة.
- **🎵 تزامن صوتي دقيق:** ربط مع `Quran.com API v4` و `EveryAyah` لدعم 10 من كبار القراء (العفاسي، عبد الباسط، المنشاوي، الحصري، المعيقلي، وغيرهم).
- **📐 مقاسات متعددة للمنصات:**
  - `9:16`: لستوري انستغرام، ريلز، وتيك توك (Vertical Reels / Shorts / TikTok).
  - `16:9`: لشاشات يوتيوب العريضة (Widescreen 1080p).
  - `1:1`: لمنشورات انستغرام المربعة (Instagram Feed).
- **⚡ تصدير الفيديو في المتصفح:** تصدير مقاطع الفيديو بجودة عالية `MP4 / WebM` محلياً عبر `HTML5 Canvas + Web Audio API + MediaRecorder` بدون الحاجة لأي سيرفر معالجة مكلف.
- **🌍 ترجمة إنجليزية فورية:** إمكانية إظهار الترجمة المعتمدة (Saheeh International) مع إمكانية التحكم الكامل بحجم الخط والخلفيات.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** HTML5, Modern CSS (Vanilla CSS & Glassmorphism), Modern JavaScript (ES Modules).
- **Rendering Engine:** HTML5 Canvas API & Web Audio API.
- **Data & Audio Sources:** Quran.com API v4, EveryAyah CDN.
- **Build Tool:** Vite.
